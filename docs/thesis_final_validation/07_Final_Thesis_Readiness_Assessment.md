## 3. What can be written as findings

1. Correlating flow logs within each capture reduced alerts by 83.28% overall: 42.09% for IoT-23 and 99.91% for Bot-IoT.
2. An incident-level detector was less accurate than fragmented per-source detectors on the same events. Macro F1 was 0.8341 vs 0.9955 and FPR 0.1021 vs 0.0046. The direction is consistent across all robustness checks and under a temporal hold-out (macro F1 0.7711 vs 0.9992).
3. The detection loss comes from the coarse incident representation, not from correlation errors. Correct incident labels would give macro F1 0.9989. All integrated false positives occur in multi-event benign incidents.
4. Adding incident context to event features changed detection only slightly, in mixed directions: F1 +0.0017 and FPR +0.0077 compared with the pooled event model. This is a diagnostic result.

## 5. Final answer to RQ1 in one paragraph (Run B evidence)

> In this experiment, integrating thirteen IoT log sources into one schema and correlating their events into incidents reduced the number of items requiring review by 83.28% (42.09% for IoT-23). However, detecting threats from incident-level summaries was less accurate than fragmented per-source detection on the same 1,692,332 held-out events: macro F1 0.834 vs 0.996, false-positive rate 10.2% vs 0.5%. The loss is attributable to the coarse incident features rather than to the correlation itself. Correlation was possible only within each capture, so the effect of correlating genuinely distributed sources remains untested.
